# Результаты проверок

Дата: 2026-11-12.

## Выполнено

На Linux установлен временный локальный .NET SDK 8.0.428 (вне репозитория). Команда:

```sh
/tmp/evolution-dotnet/dotnet test Tools/CoreTests/CoreTests.csproj --no-restore --nologo
```

Результат: **15 passed, 0 failed, 0 skipped**. Компилировались настоящие файлы `Assets/Evolution/Core`, без заглушек Unity. Тесты покрывают:

- точное наследование при нулевой вероятности мутации;
- изменения и границы признаков после 10 000 мутаций;
- энергетическую цену движения и температурного стресса;
- метаболизм без пищи и перенос питательных веществ в энергию;
- зрелость, порог и энергетический баланс деления;
- реальное рождение потомка в мире, родословную и наследование;
- голодание, старение, тепловой стресс и преимущества подходящего температурного оптимума;
- полный повтор состояния клеток, сетки, счётчиков и PRNG после 2 000 тактов с изменением среды на такте 600; проверено наличие рождений и смертей;
- различие начальных состояний при разных seed;
- ограничение численности, энергии и координат за 5 000 тактов;
- копирование и валидацию конфигурации.

Проверены JSON manifest/asmdef, уникальность GUID, наличие метаданных и ссылка сцены на скрипт. Проверены пробельные ошибки файлов.

.NET test host сообщает о необязательной переменной VSTEST_ARTIFACTS_DIRECTORY; это не ошибка тестов, все 15 тестов выполнены.

## Не выполнено

Unity Editor в окружении отсутствует. **Импорт проекта, Unity EditMode/PlayMode, компиляция Runtime/Editor сборок, шейдера и standalone player не запускались.** Версии UPM-пакетов заданы в manifest; разрешение зависимостей и генерация packages-lock.json должны пройти при первом импорте Unity. Не заявляется, что Unity-сборка успешна.

## Проверка в Unity

1. Открыть в Unity 6.3 LTS, дождаться Package Manager и убедиться, что Console не содержит ошибок.
2. При необходимости выполнить Evolution → Create or Open Cell Prototype.
3. Запустить EditMode тесты; затем Play. Проверить видимость клеток, пищи и интерфейса.
4. Дождаться роста Births/Generation, остановить Pause и убедиться, что Tick не растёт; включить 10×.
5. Установить регенерацию 0 и дождаться голодания; затем перезапустить. Проверить действие температуры и полное вымирание без автоматического восстановления.
6. Собрать standalone player, проверить наличие instancing shader и настройку URP.
7. Записать параметры и команды среды по тактам для повторения интерактивного эксперимента. Межплатформенная побитовая детерминированность не гарантируется.
