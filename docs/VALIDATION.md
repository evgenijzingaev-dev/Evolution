## Автоматические тесты

Использован .NET SDK 8.0.428 в `/tmp/evolution-dotnet`, вне репозитория:

```sh
/tmp/evolution-dotnet/dotnet test Tools/CoreTests/CoreTests.csproj --configuration Release --nologo --logger 'trx;LogFileName=core-tests.trx' --results-directory TestResults
python3 Tools/check_localization.py
```

Результат: **33 passed, 0 failed, 0 skipped**. Компилировались настоящие
исходники Core и Localization, без заглушек Unity. TRX записан в игнорируемый
`TestResults/core-tests.trx`. В тестах проверены:

- точное наследование без мутаций, изменение и границы всех пяти признаков;
- зрелость, оплачиваемая структура потомка, малый и большой размер потомка,
  ограничение его запаса собственной ёмкостью, отказ без изменения участников;
- пищевой компромисс органической специализации и цена содержания;
- общий бюджет двух ресурсов, отсутствие отрицательных остатков и сохранение
  пищи полной клеткой;
- питание органикой и её распад в настоящей Simulation;
- конечные остатки после смерти, доступность со следующего такта, отсутствие
  повторного создания остатков после вымирания;
- **по 10 000 тактов для seed 7, 42 и 123**: замкнутый энергетический баланс
  с учётом субстрата, органики, резервов и оплаченных структур; рождения,
  мутации размера, смерти, повторное потребление остатков и полное вымирание;
- совпадение клеток, обоих ресурсных полей, RNG, тактов, рождений и смертей
  при одинаковых входах, включая изменение среды;
- голодание, старение, температурный отбор, координаты, предел численности,
  копирование конфигурации и отказ при некорректных параметрах;
- русский язык по умолчанию, наличие каждого ключа, отсутствие английских
  надписей в каталоге (кроме бренда EVOLUTION и единицы °C), русские числа
  при английской системной культуре и корректность всех шаблонов.

Проверка `Tools/check_localization.py` прошла: все текущие IMGUI-надписи и
кнопки берут текст из каталога. Это проверка существующего слоя IMGUI;
новые способы вывода текста потребуют расширения проверки. NUnit и проверка
мест вывода подключены к `.github/workflows/core-tests.yml`.

Дополнительно проверены JSON manifest/asmdef, метаданные всех Unity assets,
**25 уникальных GUID**, ссылка сцены на скрипт и `git diff --check`.
`git diff origin/migration/godot-reference -- Reference/Godot` пуст:
ни один файл референса не изменён.

## Измерение ядра без Unity

Воспроизводимый запуск:

```sh
dotnet run --project Tools/CoreBenchmarks/CoreBenchmarks.csproj --configuration Release
```

Linux x64, .NET 8.0.428, Release, seed 42, сетка 64×64, шаг 0.05 с.
Для каждого размера — 100 прогревочных и 500 измеряемых тактов,
восстановление субстрата 0.5/с, возрастной предел 10 000 с.
Вместимость равна стартовой численности: это плотная нагрузка питания и
движения, а не худший случай массовых рождений/смертей.

| Стартовая численность | В конце | Среднее время такта, мс | Выделено байт в измеряемом цикле |
| --- | --- | --- | --- |
| 1 000 | 1 000 | 0.1947 | 0 |
| 4 096 | 4 096 | 1.0087 | 0 |
| 10 000 | 9 999 | 2.4750 | 0 |

Облачный хост даёт заметный разброс: предварительный запуск того же ядра
показал примерно 0.14/0.52/1.26 мс. Это ориентир сложности и выделений,
а не порог производительности, сравнение с Godot или обещание кадров/с.
Mono/IL2CPP, Unity Profiler, графика и максимальные всплески не измерены.

## Unity: проверка не выполнена

Попытка запуска:

```sh
Unity -batchmode -nographics -projectPath /workspace/Evolution -runTests -testPlatform EditMode -testResults /tmp/evolution-unity-editmode.xml -logFile /tmp/evolution-unity-tests.log
```

Вернула **127: `Unity: command not found`**. Редактор также не обнаружен
в стандартных каталогах `/opt/unity` и `/opt/Unity`.
Импорт пакетов, компиляция Runtime/Editor, Unity Test Runner, Play Mode,
шейдер и standalone player здесь не проверены. URP 17.3.0 и Test Framework
1.6.0 оставлены из прототипа; совместимость с Unity 6.6 ещё нужно подтвердить.

Честная проверка на машине с Unity 6.6.9f1:

1. Дождаться импорта и компиляции без ошибок; выполнить EditMode-тесты.
2. Запустить `Assets/Evolution/Scenes/CellPrototype.unity`. Проверить кириллицу,
   русские подписи, запятые в числах, прокрутку панели и оба режима цвета.
3. Проверить «Пауза»/«Продолжить», ускорение ×10, температуру,
   восстановление субстрата, повтор с тем же зерном и камеру.
4. Для быстрых смертей поставить `Max Age = 20` до запуска: убедиться,
   что коричневые остатки появляются и их запас меняется. Отключить
   восстановление субстрата и проверить конечность запасов/вымирание.
5. Проверить несколько зерён и старт от одной клетки. Измерить CPU/GC/GPU
   и время кадра на 1/4/10 тыс. клеток; собрать и запустить standalone player.

Windows-клоны пользователя и оригинальный Godot-проект недоступны этой
облачной среде и не изменялись. PR #1 не сливался; новые изменения подготовлены
отдельным PR к ветке референса. Issue #2 остаётся планом следующих этапов.
