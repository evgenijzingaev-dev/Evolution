# Игровой интерфейс 3D-океана

База: PR #19, Unity 6000.6.9f1 / URP. Интерфейс создаётся средствами Unity;
растровой подложки с нарисованными кнопками нет. Небольшие генерируемые текстуры
используются только для скругления панелей и точек карты. Вода и организмы —
прежняя сцена, не новая визуальная модель.

## Композиция

Полупрозрачные тёмно-синие панели, мягкий голубой контур, светлый Open Sans с
кириллицей, зелёная шкала реального запаса энергии. Верхняя навигация, задачи
слева, карточка клетки справа, карта снизу слева, компактные действия по центру
снизу и строка состояния. Окно развития и настройки открываются отдельно.
Новая панель плавно появляется при смене раздела/уровня детализации.

Никакая часть центральной сцены не заменяется изображением референса. Иконки
действий условные и минимальные; художественное качество оценивается по настоящим
кадрам Unity, а не только по исходникам.

## Управление

| Действие | Мышь / кнопка | Клавиатура |
| --- | --- | --- |
| Взять управление | «Игра за клетку» / «Движение» | — |
| Плыть | Щелчок по свободной воде | WASD |
| Менять глубину | Через направление камеры при щелчке | Q / E |
| Ускориться | — | Shift |
| Разрешить укусы в досягаемости | Переключатель «Атака» | Удерживать Space |
| Подсветить пищу | «Питание» | — |
| Вращать камеру | ПКМ | — |
| Масштабировать вид | Колесо над миром | — |
| Масштабировать карту | Колесо над картой / ×2 | — |
| Выбрать клетку / область | Мир / карта | Tab: следующая клетка в игре |
| Сменить вид обзора | Кнопка вида | Tab в обзоре |
| Сменить уровень данных | Кнопка справа сверху | F2 |
| Подсказки | ? | F1 |
| Пауза | Строка снизу | P |
| Скрыть интерфейс | — | H |
| Назад | — | Esc |

Щелчок задаёт цель в плоскости, проходящей через клетку поперёк направления
камеры. Поверните камеру или используйте Q/E для движения по третьей оси.
При ручном WASD/Q/E заданная мышью цель отменяется. Это только преобразование
в существующий `World.Input`; физика и расходы энергии не меняются.
Ввод над кнопками/картой не передаётся в сцену. Нажатие Space в обычной игре
сохраняет укус; F1/F2 не пересекаются с прежними клавишами камеры.

Пища усваивается автоматически при попадании внутрь облака. «Питание» включает
навигационную подсветку, а не создаёт отдельное фиктивное действие поедания.
Хищничество доступно только с геном Predation > 0.2, энергией > 0.5 и при взятом
управлении. Возможность реального укуса дополнительно проверяет сама модель.

## Достоверность данных

`PlayerReadout` — отдельная читающая проекция. Не меняет клетку, ресурсы, часы,
случайные числа или загруженные регионы. Обновляется дважды в секунду.

| Игровой показатель | Источник / смысл |
| --- | --- |
| Энергия | Energy / Biology.Capacity, ограничено 0…100% |
| Состояние | Alive, Integrity (<0.4 повреждена, <0.8 есть повреждения), Energy (<20% нужна энергия) |
| Температура | Biology.Efficiency с PreferredTemperature и ThermalTolerance: ≥85% комфортно, ≥65% умеренный дискомфорт, иначе некомфортно |
| Течение | Current.Length / Ecology.Mobility: <0.35 слабое, <1 умеренное, иначе сильное |
| Свет | Sample.Light: <0.2 темно, <0.7 достаточно, иначе ярко |
| Питание | FoodPotential за секунду относительно Biology.Cost; <1 расхода мало, <2 достаточно, иначе много |
| Доступная пища | Облака с положительным FoodPotential в радиусе чувствительности плюс радиус самого облака; выбор учитывает расстояние до границы облака |
| Опасность | Живая клетка в SenseRadius, Ecology.CanHunt и сила реального укуса >0.28 после защиты |
| Популяция / линии | Живые Survey.Agents в загруженной области и выбранном слое |

Питание — оценка потенциального дохода в ближайшем облаке, а не текущий запас
пищи внутри организма. Он не изображается в виде выдуманной шкалы насыщения.
Целостность соответствует повреждению настоящей оболочки; отдельная шкала
«здоровья» не добавляется. Задача при угрозе имеет приоритет над поиском пищи.

Научный уровень показывает XYZ, скорости, ID, энергию, целостность, возраст,
поколение, свет, температуру, вектор течения, составляющие энергетического бюджета,
все поля генома, запасы и концентрацию выбранного источника пищи, tick, чанки и
частицы. Это прокручиваемая карточка только для чтения.

## Обзор и карта

Карта показывает текущие позиции клеток, реальные облака пищи, выбранную клетку,
направление камеры и угрозы. X/Z — горизонтальная проекция; глубина обозначена
цветом, либо явно выбран срез Y шириной 20 условных единиц. Координата Y не
названа метрами, поскольку масштаб модели условный.
Кнопки −/+ выбирают соседний слой. Карта масштабируется и позволяет приблизиться
к реальной клетке либо перейти в точку на выбранной высоте. В обычной игре слой
ограничивает карту; отсечение мира работает в стратегическом обзоре как раньше.

В аналитическом обзоре доступны прежние девять информационных слоёв, переход
к самой населённой наблюдаемой области, запасам пищи и области недавних атак.
Из «Развития» можно выбрать и отслеживать генетическую линию. Удалённые архивные
числа не добавляются к счётчику текущего населения. Это не перепись бесконечного океана.

Уведомления: фактическое усвоение энергии, реальный близкий хищник, найденные
подходящие ресурсы, подтверждённое исчезновение линии или уменьшение наблюдаемой
численности региона. Не более трёх в очереди, двух на экране; 7 секунд показа и
18 секунд между повторами одного типа. Выгрузка чанка не объявляется вымиранием.

## Границы реализации

В 3D нет деления, новых мутаций при размножении, колоний и редактора развития.
Раздел «Развитие» показывает существующие наследуемые черты и честно объясняет
ограничение. Прогресс деления и рождения не имитируется. Мембрана даёт пассивную
защиту по существующей модели; отдельная активная защитная способность не заявляется.

Масштаб интерфейса 0.8…1.25 сохраняется в PlayerPrefs; максимальный реальный размер
ограничивается компоновкой экрана, чтобы панели помещались. Три целевых разрешения:
1920×1080, 2560×1440 и 1366×768. Геометрический LayoutFits проверяется в плеере;
дополнительно необходимо визуально оценивать переносы текста и мышиный ввод.

- 20-ui-2560x1440.png — настоящий framebuffer 2560×1440;
- 21-development-ui.png — честный раздел развития.

Поиск опасности использует только существующих организмов. При необходимости
неизменённая модель продвигается максимум на 400 тиков. Если опасность не найдена,
кадр не выдаётся за подтверждение предупреждения: `threatIndex` отрицателен, а
валидатор сообщает `dangerCaptureAvailable=false`. Чужие старые кадры не являются
доказательством этого PR. Manifest содержит реальную ревизию, версию Unity, GPU,
размеры каждого framebuffer, страницу и детализацию HUD, угрозу, пищу и проверку
компоновки. Наличие настоящих PNG проверяется отдельно от художественной оценки.
