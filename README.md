# Дом №13 — Тёмные окна (Noir Edition 3.0)

Мобильная интерактивная детективная игра на HTML, CSS и JavaScript. Работает без серверных API, рекламы и сборщиков. Это веб-игра/PWA, не APK.

## Что нового

- Полностью новая визуальная режиссура: приглушённая палитра, ночной город, архитектурный фасад, дождь, освещение в окнах, ощущение наблюдения.
- Силуэты шести жильцов выполнены в сдержанной векторной эстетике; в диалогах вместо эмодзи отображаются портреты.
- Новые стили досье, модальных окон, нижнего меню и иллюстрированной доски улик.
- Каждое из пяти расследований завершается **двухэтапной дедукцией**: сначала версия, затем главная подтверждающая улика. За подкреплённый правильный вывод даются дополнительные очки.
- Исправлены действия при отсутствии жильца: недоступны разговор и помощь, а изучение пустой квартиры не может создавать свидетельские показания.
- Содержимое старой версии 2.2 сохранено: история времени 22:13, загадочная посылка, чердачная запись, письма и комната №0.

## Установка и запуск

Откройте `index.html` рядом с `game.js`, `vibe.css`, `noir.css`, `scene-background.svg`, иконками, `sw.js` и `manifest.webmanifest`. Для надёжного PWA/offline нужен HTTPS-хостинг с service worker; например GitHub Pages. Из `file://` отдельные возможности браузера могут работать ограниченно.

Исходники ведутся в репозитории `evgenijzingaev-dev/Evolution`, в `mini-games/dom-13/` ветки `feature/dom-13-mobile-prototype`. Также может быть опубликована подготовленная ветка `dom13-pages` — файлы игры в корне.

## Проверки

`node --check game.js` и `node --check sw.js` прошли. Через Chromium Playwright с инлайн-ресурсами проверено: отсутствие показаний пустой квартиры; невозможность говорить с отсутствующим соседом; прохождение всех пяти дел с выбором подтверждающей улики; начисление очков; отсутствие JS-ошибок и горизонтальной прокрутки при ширинах 320, 390, 510 px. Само HTTPS-развёртывание и установка на Android ещё требуют отдельной проверки.

## Примечание о сохранениях

Текущая схема сохранений — `dom13-nightshift-v4` в localStorage. Если предыдущая версия уже создала сохранение v4, прогресс сохраняется. Ещё более старые v2/v3 не переносятся автоматически из-за несовместимости расследований.

## Исправление 3.1 — отдельный результат действий

После выбора жильца результат наблюдения/беседы всегда выводится в блоке «Твоё последнее действие». Случайные события соседей находятся отдельно в блоке «В это время в доме», поэтому они больше не подменяют беседу с Львом, Кирой или другими жильцами. У каждого жильца есть пять уникальных фраз — по одной на дело, а улики строго привязаны к владельцу квартиры. Разговор с отсутствующим жильцом недоступен. Текущие сохранения формата v4 продолжают использоваться; добавленные поля восстанавливаются автоматически.
