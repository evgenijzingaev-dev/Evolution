# EVOLUTION: LIFE BEYOND

Цель — путь от одной клетки до сложных организмов и экосистем на разных
планетах через генетику и естественный отбор, без обязательной цепочки видов.
Реализованы клеточное ядро и этап 2 — зарождение многоклеточности:
наследование, мутации, оплачиваемое размножение, питание, конечные органические
остатки, устойчивые колонии, развитие функций и обмен энергией.
Основа этого этапа — PR #3, коммит `4e35b4d`; системы питания и русский UI сохранены.

Целевой редактор — **Unity 6.6.9f1 (6000.6.9f1)**, C#, URP.
Пакет URP пока закреплён на 17.3.0 из исходного прототипа; импорт и совместимость
в целевом редакторе нужно подтвердить. Текущий 3D-прототип — лабораторная чашка
на плоскости XZ с периодическими границами. Это ещё не полноценный мир.
Godot в `Reference/Godot/` используется только как референс механик.
**Русский — язык игры по умолчанию.** Строки выделены в `Evolution.Localization`.

## Запуск

1. Откройте корень репозитория через Unity Hub в Unity 6.6.9f1. Дождитесь импорта пакетов и компиляции.
2. При первом импорте редактор создаст URP renderer и pipeline в `Assets/Evolution/Settings` и откроет сцену. Если нужно, вызовите **Evolution → Create or Open Cell Prototype**.
3. Откройте `Assets/Evolution/Scenes/CellPrototype.unity` и нажмите Play.
4. В игровом окне доступны «Пауза»/«Продолжить», 1×/2×/5×/10×, температура, восстановление субстрата, повтор с тем же зерном генерации и приближение камеры. Панель показывает численность, рождения, смерти, поколение, энергию и средние признаки. Переключатель цвета показывает функции клеток (по умолчанию), температурный оптимум или пищевую специализацию. Новые показатели: число колоний и их клеток, крупнейший организм, транспорт энергии, адгезия, развитие тканей, наследуемый предел размера и ветвление. Зелёный грунт — субстрат, коричневые участки — конечные органические остатки.
5. Зерно генерации (`Seed`) и начальные параметры задаются на компоненте Evolution Simulation до запуска. Для старта от одной клетки задайте `Initial Population = 1`. По умолчанию 160 основателей позволяют быстрее наблюдать отбор. Изменения в инспекторе во время игры применяются только после кнопки «Начать заново с тем же зерном».

При росте температуры холодолюбивые клетки теряют больше энергии, хуже усваивают пищу и реже делятся. Быстрое движение и высокий захват пищи имеют энергетическую цену. В условиях голода популяция может полностью вымереть — автоматического заселения нет.

Родитель оплачивает запас и формирование потомка с учётом его размера. После
смерти часть оплаченной энергии остаётся в локальной органике. Специализация
на органике наследуется и мутирует: улучшает её усвоение, но снижает выход
энергии из субстрата и повышает затраты на содержание. Восстановление субстрата
считается внешним притоком энергии; один рециклинг не даёт бесконечной жизни.

Для короткого опыта с остатками до запуска задайте `Max Age = 20`.
Для закрытого мира задайте `Nutrient Regeneration = 0`: запас конечен,
вымирание допустимо. `Initial Organic Energy` задаёт стартовый запас энергии
органики **на каждый узел**, `Organic Decay Rate` — долю распада в секунду.

## Многоклеточная жизнь

Колонии возникают при встрече генетически совместимых клеток с достаточной
адгезией либо при удержании оплаченного потомка. В геноме нет обязательного
этапа эволюции: одиночные клетки продолжают жить и размножаться. Связи образуют
устойчивое дерево с общим движением; ген `Branching` задаёт нить или ветвящееся
тело. Оболочка и объёмные перемычки визуально объединяют организм, а органеллы
и форма показывают постепенно развивающиеся функции:

- питающие клетки усиливают поглощение пищи;
- двигательные клетки ускоряют организм;
- защитные клетки смягчают температурный стресс группы;
- репродуктивные клетки раньше созревают и делятся при меньшей доле резерва.

У специализации есть цена: остальные функции ослабевают, содержание тканей
расходует энергию, большой организм испытывает сопротивление движению.
Передача идёт только по существующим связям и градиенту наполнения резервов;
скорость зависит от обоих геномов, 5% передаваемой энергии теряется.
При смерти клетки дерево распадается на жизнеспособные компоненты;
одиночный выживший постепенно теряет специализацию.

`Max Colony Cells` ограничивает организм (по умолчанию 16); наследуемый предел
`2 + floor(10 × ColonySize)` обычно строже. Лимит учитывает всех участников.
`Capacity` ограничивает **общее число клеток**, включая клетки колоний.
Заполненная колония выпускает оплаченных свободных потомков; ни сборка
колонии, ни специализация не создают новые клетки или энергию бесплатно.
Новые гены наследуются с ограниченными мутациями; функции развиваются заново
у каждого потомка. Подробности и коэффициенты — [ARCHITECTURE.md](docs/ARCHITECTURE.md).

Для наблюдения: запустите штатную сцену с `Seed = 42`, ускорьте время и
приблизьте камеру. Перемычки сохраняют форму тела при движении; на краях мира
оно продолжается через периодическую границу. Панель прокручивается и содержит
русские пояснения функций и компромиссов. Наблюдение в Unity ещё требуется:
редактор в облачной среде отсутствует, скриншоты и player build не получены.

## Тесты

В Unity: **Window → General → Test Runner → EditMode → Run All**.

Без Unity, при установленном .NET 8 SDK:

```sh
dotnet test Tools/CoreTests/CoreTests.csproj
python3 Tools/check_localization.py
```

Этот проект компилирует непосредственно исходники Core и те же NUnit-тесты. Он проверяет биологию, но не Unity API, импорт, шейдеры или сборку игры.
Также проверяются русский каталог, форматирование чисел и отсутствие прямых
надписей в текущих местах вывода IMGUI. Эти же проверки запускаются в GitHub Actions.

Пакетный запуск Unity (путь к executable зависит от ОС):

```sh
Unity -batchmode -projectPath "$PWD" -executeMethod Evolution.Editor.PrototypeSetup.CreatePrototype -quit -logFile setup.log
Unity -batchmode -nographics -projectPath "$PWD" -runTests -testPlatform EditMode -testResults TestResults/editmode.xml -logFile tests.log
```
