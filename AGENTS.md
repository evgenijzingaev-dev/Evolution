# EVOLUTION: обязательные требования следующих этапов

- Целевой Unity Editor: **6000.6.9f1**.
- Всегда сохранять встроенный аудиомодуль Unity в `Packages/manifest.json`:
  `"com.unity.modules.audio": "1.0.0"`. Не удалять эту зависимость при следующих
  этапах, обновлении пакетов или подготовке чистого проекта.
- `OceanAudio` и `EvolutionRunner` используют настоящие Unity `AudioClip`,
  `AudioSource` и `AudioListener`; аудиомодуль должен входить в Git вместе
  с игровыми исходниками. Не заменять эти типы заглушками для обхода компиляции.
- После изменения пакетов проверять корректность JSON и наличие указанной
  зависимости. При доступном Unity Editor проверять чистое клонирование без
  `Library`: дождаться восстановления пакетов и компиляции в 6000.6.9f1,
  убедиться в отсутствии ошибок разрешения этих трёх типов, затем запустить
  CellPrototype и существующие PlayMode smoke-тесты звука.
- Если Unity Editor недоступен, явно отделять статическую проверку манифеста
  от неподтверждённого чистого импорта/компиляции. Не запускать тяжёлые сборки
  вместо коротких проверок без необходимости.

## Постоянная игровая студия

- Команда субагентов живёт в `.agents/` (13 ролей: `studio-lead`,
  `product-owner`, `team-manager`, `technical-director`, `engine-programmer`,
  `art-director`, `content-designer`, `narrative-designer`, `ux-designer`,
  `audio-designer`, `game-analyst`, `code-reviewer`, `devops-engineer`).
- Состав, правила делегирования, матрица владения и журнал проверок —
  [docs/STUDIO_TEAM.md](docs/STUDIO_TEAM.md).
- Для крупной вехи запускать `studio-lead`; он параллелит только задачи без
  общих файлов, интегрирует результат и передаёт diff `code-reviewer`.
- Не выдавать роли за результат: каждый вызов должен вернуть артефакт, тест или
  проверяемый вердикт. Если сессия не загрузила `.agents`, сказать об этом прямо
  и не имитировать работу студии.
