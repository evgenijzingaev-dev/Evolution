# Дом №13 — Ночная смена (версия 1.0)

Мобильная детективная игра без сервера, сборщика, аналитики и платных API. HTML + CSS + обычный JavaScript. Работает в мобильном браузере в портретном режиме. Прогресс и настройки хранятся локально в браузере, на этом устройстве.

## Содержание кампании

- Дело 1. Кто гасит свет?
- Дело 2. Пропавшие посылки.
- Дело 3. Голос на чердаке.

В каждом деле по шесть улик и три версии событий. Для выдвижения версии достаточно трёх улик. У игрока ограничены время и внимание, есть шкала напряжения, небольшие развилки-события, доверие жильцов, общая система очков и разные исходы. Между делами сохраняются доверие к жильцам, добрые дела и общий счёт. После трёх дел — финал кампании и возможность переиграть.

## Запуск

Откройте `index.html` в браузере рядом с файлами `game.js`, `manifest.webmanifest`, `sw.js` и `icon.svg`. Для установки как веб-приложения и офлайн-кеша нужен HTTPS-хостинг (например, GitHub Pages), поддерживающий service worker. `file://` может блокировать доступ к сохранениям в некоторых браузерах; рекомендуется HTTP(S).

На GitHub Pages для репозитория с каталогом `mini-games/dom-13/` требуется отдельная публикация этой папки (например, через GitHub Actions или отдельный репозиторий), поскольку Pages не предлагает произвольную подпапку как источник.

## Мобильное управление

1. Нажмите на окно жильца.
2. Выберите: наблюдать, слушать, поговорить или помочь.
3. Каждое действие расходует единицу внимания и один игровой час; «След. час» восстанавливает две единицы внимания.
4. На определённых часах появляются события с выбором.
5. После трёх улик откройте «Версии» и выберите объяснение событий.
6. Перейдите к следующему делу или начните новую кампанию.

## Проверки

Проверено в Chromium/Playwright: правильные решения всех трёх дел, переходы между делами, обязательное событие с выбором, повторная кампания, получение доверия за помощь, отсутствие исключений JavaScript и горизонтальной прокрутки на ширине 320–510 пикселей. Отдельно проверен синтаксис `game.js`. Проверка установки PWA, service worker и сохранения с полноценным HTTPS-адресом остаётся на этапе публикации на постоянном хостинге.

## Файлы

- `index.html` — интерфейс, верстка, тема и подключение игры.
- `game.js` — игровые данные и логика.
- `manifest.webmanifest` — информация об устанавливаемом веб-приложении.
- `icon.svg` — иконка.
- `sw.js` — кеширование приложения для офлайн-запуска на поддерживаемом HTTPS-хостинге.
