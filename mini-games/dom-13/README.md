# Дом №13: Ночная смена

Короткая одиночная мобильная детективная игра. Наблюдай за шестью жильцами, слушай, разговаривай, помогай соседям, собирай улики и разгадай причину ночных отключений электричества.

## Как запустить

Открой `index.html` в браузере на телефоне или компьютере. Сборка, сервер, установка и доступ к сети не требуются. Для постоянной ссылки можно опубликовать этот каталог через GitHub Pages или любой статический хостинг.

## Правила

- На изучение квартиры тратится 1 единица внимания и 1 игровой час.
- «След. час» восстанавливает 2 внимания и продвигает время на час.
- Собери минимум 3 улики, после чего открой «Версии».
- Для лучшего финала собери хотя бы 5 улик, соверши доброе дело и удержи напряжение дома не выше 55%.
- История длится три игровых вечера. При напряжении 100% или окончании третьего дня наступает поражение.
- Прогресс хранится в `localStorage` на устройстве. Есть сброс и повторная игра.

## Технологии

Один автономный HTML-файл: HTML, CSS и JavaScript, без фреймворков, трекеров, платных API и внешних зависимостей. Мобильная вёрстка, поддержка клавиатуры, уменьшенного движения и системных safe areas.
