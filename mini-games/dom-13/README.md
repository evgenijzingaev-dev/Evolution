# Дом №13 — Ночная смена · Midnight Rain Edition (2.1)

Атмосферная детективная веб-игра для телефона. **5 расследований**, 6 жителей, 30 улик, события с последствиями, достижения и личные истории жильцов. Всё работает без серверов, рекламы и платных API.

## Визуальное обновление

- Новый ночной двор: авторская SVG-панорама города с луной, мокрым асфальтом, деревьями и тёплым светом фонарей.
- Многослойный анимированный дождь, атмосферные отблески окон, детальная крыша и кирпичные фасады.
- В квартирах появились полки, лампы, картины и растения; у шести соседей теперь собственные нарисованные SVG-портреты.
- Мягкие переходы, световые акценты, более объёмные панели и новый стиль диалогов.
- Атмосферный звук дождя включается отдельно в **Журнале** только после нажатия игрока; по умолчанию выключен.
- Эффекты движения учитывают системную настройку `prefers-reduced-motion`.

## Как играть

Тапни по окну и выбери действие: наблюдать, слушать, поговорить или помочь. Потраченное внимание восстанавливается кнопкой «След. час». Собери минимум три улики и выбери версию на вкладке «Версии». Доверие, решения и результаты пяти дел учитываются в финале. Журнал показывает улики, последние события, достижения, подсказки и настройки звука.

## Файлы

- `index.html` — интерфейс и базовая структура.
- `vibe.css` — атмосферная тема и анимация (CSS).
- `scene-background.svg` — оригинальная ночная панорама.
- `game.js` — сюжет пяти дел, состояния и оригинальные SVG-персонажи.
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon.svg`, `sw.js` — PWA.

## Запуск

Открой `index.html` рядом со всеми перечисленными файлами. Для установки на главный экран и офлайн-кеша нужен HTTPS-сайт, например GitHub Pages, и один онлайн-запуск. Локальные сохранения зависят от браузера; смена домена может не переносить прогресс. Это **веб-приложение, не APK**.

### GitHub Pages

Проект хранится в `feature/dom-13-mobile-prototype` как `mini-games/dom-13/`. Для отдельного сайта без объединения с основной игрой подготовлена ветка `dom13-pages`, содержащая файлы приложения в корне. **Владелец** репозитория может включить Pages в Settings → Pages → Deploy from a branch → `dom13-pages` / `/(root)`, если Pages ещё не настроен для другого сайта. Переключать уже действующий сайт без проверки нельзя.

## Проверки

`node --check` для `game.js` и `sw.js`. В Playwright/Chromium проверены пять дел, переходы и выборы, сохранение через mock-localStorage, подсказки, обязательные события, отсутствие JS-исключений и горизонтальной прокрутки 320–510 px. Все графические ресурсы подключены при тестовой инлайн-загрузке, так как доступ к локальному HTTP в среде теста заблокирован. Реальное кеширование/установка PWA на HTTPS ещё не проверены.
